# پل تجارت — نمونهٔ وب‌سایت بازرگانی

یک صفحهٔ معرفی فارسی و راست‌چین برای شرکت بازرگانی عمومی؛ با تمرکز بر معرفی خدمات، توضیح مسیر همکاری، نمایش حوزه‌های نمونه و گرفتن درخواست مشاوره.

## اجرا

پروژه به هیچ وابستگی یا فرایند build نیاز ندارد. `index.html` را در مرورگر باز کنید یا از پوشهٔ پروژه یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

## سفارشی‌سازی پیش از انتشار

- «پل تجارت» و نشان آن صرفاً نام و هویت پیشنهادی‌اند؛ نام، لوگو و متن‌ها را با مشخصات واقعی شرکت جایگزین کنید.
- حوزه‌های کالا و خدمات را مطابق فعالیت واقعی شرکت ویرایش کنید.
- تصویر اصلی در `assets/trade-port.jpg` قرار دارد و می‌تواند با تصویر اختصاصی شرکت عوض شود.
- فرم فعلاً نمایشی است و اطلاعات را جایی ارسال یا ذخیره نمی‌کند. پیش از انتشار، آن را به ایمیل شرکت یا یک سرویس/backend فرم متصل کنید.
- شماره تماس، نشانی و شبکه‌های اجتماعی عمداً درج نشده‌اند تا اطلاعات ساختگی نمایش داده نشود.

## فایل‌ها

- `index.html` — ساختار و متن صفحه
- `styles.css` — چیدمان واکنش‌گرا، رنگ‌ها و حالت‌های تعاملی
- `script.js` — منوی موبایل، ظاهرشدن تدریجی بخش‌ها و پیام فرم نمونه
- `assets/trade-port.jpg` — تصویر بخش آغازین
