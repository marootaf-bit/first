# first

## سرور MCP فیگما (Figma)

پیکربندی سرور remote فیگما در فایل‌های زیر اضافه شده است:

| کلاینت | فایل |
| --- | --- |
| Claude Code / Claude Desktop | `.mcp.json` |
| VS Code / GitHub Copilot | `.vscode/mcp.json` |
| Cursor | `.cursor/mcp.json` |

نکته: این سرور از OAuth استفاده می‌کند. اولین باری که کلاینت به
`https://mcp.figma.com/mcp` وصل می‌شود، مرورگر باز شده و باید با حساب فیگما
خود اجازه‌ی دسترسی بدهید.

## احراز هویت (لاگین)

ثبت آدرس در فایل پیکربندی فقط سرور را «معرفی» می‌کند؛ تا وقتی مرحله‌ی OAuth را
در مرورگر تأیید نکنید، وضعیت آن `disconnected` می‌ماند.

**Claude Code (ترمینال)**

```bash
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

سپس داخل Claude Code دستور `/mcp` را بزنید، `figma` را انتخاب کنید و
**Authenticate** را بزنید. مرورگر باز می‌شود ← با حساب فیگما لاگین کنید ←
**Allow** را بزنید. اگر از فایل `.mcp.json` استفاده می‌کنید، Claude Code را
یک‌بار کاملاً ببندید و دوباره باز کنید تا سرور پروژه را شناسایی کند (ممکن است
ابتدا بپرسد آیا سرورهای این پروژه را تأیید می‌کنید).

**VS Code / GitHub Copilot**

کلید `Ctrl+Shift+P` → `MCP: List Servers` → سرور `Figma` را **Start** کنید →
مرورگر برای لاگین باز می‌شود → تأیید دسترسی.

**Cursor**

`Settings → Tools & MCP` → ورودی `Figma` → دکمه‌ی **Sign in / Connect** →
تأیید در مرورگر.

## عیب‌یابی

- وضعیت `disconnected` ماند: یعنی احراز هویت در مرورگر کامل نشده است.
- فایلی که می‌خواهید خوانده شود باید دست‌کم دسترسی «Can view» داشته باشد.
- سرور **Remote** روی همه‌ی پلن‌ها (حتی رایگان) کار می‌کند؛ سرور **Desktop**
  محلی (`http://127.0.0.1:3845/mcp`) به Dev seat یا Full seat نیاز دارد.
- اگر روی ماشین راه‌دور/SSH کار می‌کنید، مرورگر باید روی همان ماشینی باز شود
  که کلاینت روی آن اجرا می‌شود، چون کال‌بک OAuth به `localhost` برمی‌گردد.
